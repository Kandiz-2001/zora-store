# ZORA luxury storefront starter

A responsive luxury-fashion e-commerce front end built with HTML5, Bootstrap 5, custom CSS and vanilla JavaScript.

## Run it
1. Extract the ZIP.
2. Open `index.html` in a browser, or use VS Code Live Server.
3. Internet is needed for Bootstrap, Bootstrap Icons, Google Fonts and the Unsplash demo images.

## Included
- Editorial home page, campaign sections, categories and journal cards
- Product grid with category filters, search and price sorting
- Quick-view product modal
- Wishlist and shopping bag with quantity controls
- Cart and wishlist persisted in browser localStorage
- Responsive mobile navigation and layouts
- Newsletter interaction (front-end demo)
- Accessible labels and reduced-motion support

## Important
This is a front-end prototype, not a production commerce backend. Product information is sample content and prices are illustrative USD amounts. Checkout, authentication, inventory, real shipping/tax calculations, email capture and payment processing are not connected. Before launch, connect a backend/database, secure authentication, order management and a payment provider such as Paystack or Stripe. Replace sample images with licensed ZORA product photography. Do not use Gucci, Louis Vuitton or Versace logos, product photography or distinctive brand assets.
